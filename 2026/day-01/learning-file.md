# 90-Day DevOps and Cloud Engineering Learning Plan

## Current Understanding

My understanding of DevOps and Cloud Engineering is that they focus on building reliable, scalable, automated, and observable software delivery systems. DevOps is not limited to deployment automation; it involves understanding how applications, infrastructure, networking, monitoring, security, CI/CD, containers, and cloud platforms operate together in production environments.

Cloud platforms such as AWS and Azure provide the infrastructure and managed services that support modern application delivery, scalability, resilience, and operational efficiency. The goal is to understand not only how systems are deployed, but how they fail, recover, scale, and are continuously maintained.

## Why I Am Learning DevOps and Cloud

I am transitioning from a general software engineering background toward infrastructure and deployment engineering because I want to understand how real production systems operate at scale.

My focus is on:
- Understanding production-grade infrastructure workflows
- Learning deployment and release engineering practices
- Understanding containers, Kubernetes, networking, CI/CD, observability, and Infrastructure as Code
- Learning how applications are packaged, shipped, monitored, and maintained
- Understanding system failures, debugging, recovery, and operational reliability
- Learning how AWS and Azure services support modern engineering workflows
- Understanding AI-era infrastructure patterns and deployment workflows

The long-term objective is to become capable of solving real infrastructure, automation, and deployment problems in large-scale engineering environments.

## 90-Day Target

By the end of the next 90 days, I want to build a strong practical foundation in modern DevOps and Cloud Engineering workflows.

### Realistic Goals
1. Build and deploy containerized applications using Docker, GitHub Actions, and AWS services
2. Learn Kubernetes fundamentals, deployments, networking, scaling, and monitoring basics
3. Create Infrastructure as Code setups using Terraform for repeatable cloud provisioning

## Core Skills To Build

1. Cloud Infrastructure and Networking
   - AWS core services, VPCs, compute, storage, IAM, and networking basics

2. Containers, CI/CD, and Automation
   - Docker, Kubernetes basics, GitHub Actions, deployment pipelines, and automation workflows

3. Observability and Reliability
   - Logging, metrics, monitoring, tracing, alerting, debugging, and incident understanding

## Weekly Study Allocation

| Area | Hours/Week |
|---|---:|
| Linux, Networking, Git | 4 |

## Daily Consistency Strategy

- Study daily with fixed time blocks instead of irregular long sessions
- Prioritize hands-on implementation over passive content consumption
- Maintain personal notes for architecture concepts, commands, and troubleshooting observations
- Build small repeatable projects instead of collecting tutorials
- Review failures, deployment issues, logs, and debugging steps carefully
- Spend time understanding why systems behave a certain way instead of only following setup instructions
- Track weekly progress with practical checkpoints and project-based outcomes

## Long-Term Direction

This 90-day period is intended to build discipline, operational understanding, and foundational engineering skills required for long-term growth in DevOps and Cloud Engineering. The objective is not fast certification collection, but developing practical capability in modern infrastructure and software delivery systems.
